# dgp-assets

Miroir CDN des fonds d'ecran statiques des themes Display DG PILOT.

Ces fichiers sont deja servis publiquement, sans authentification, depuis
`https://change-display-demo.web.app/images/`. Ce depot n'expose aucune donnee
nouvelle : aucune information agence, aucun identifiant client, aucun secret.

Objectif : servir la bande passante de ces images depuis GitHub Pages afin de
ne pas saturer le quota de transfert Firebase Hosting.
